# אוצר שלמה בטלפון (אנדרואיד)

אותה תוכנה, אותו מאגר, על הטלפון: חיפוש עברי מלא, כרטיסים, הערות, קטגוריות,
עריכה — הכול **מקומי בטלפון** ועובד בלי רשת. עם שרת סנכרון (ADR-039) הטלפון
והמחשב המרכזי רואים אותו מאגר. ADR-040 מתעד את ההחלטות.

## התקנה

1. בטלפון, פותחים בדפדפן את דף השחרורים:
   https://github.com/enadot/yanuka-db/releases
2. בגרסה האחרונה, מורידים את `OtzarShlomo_<גרסה>_android.apk`.
3. פותחים את הקובץ שהורד (מההודעה "ההורדה הושלמה" או מאפליקציית "קבצים").
4. אנדרואיד ישאל פעם אחת אם לאפשר לדפדפן להתקין אפליקציות ("התקנת אפליקציות
   לא ידועות") — מאשרים. זו ההרשאה שמאפשרת התקנה שלא דרך Google Play; היא
   ניתנת לאפליקציה אחת (הדפדפן/מנהל הקבצים) ואפשר לבטל אותה אחרי.
5. "התקנה" → מסיימים. האייקון "אוצר שלמה" במסך הבית.

אין צורך בחשבון Google, בחנות, או בהרשמה. אף אחד לא רואה את האפליקציה חוץ
ממי שיש לו את הקישור.

**Play Protect** עשוי להציג אזהרה על אפליקציה שלא נסרקה. "התקן בכל זאת" — זו
האפליקציה שלך, שנבנתה מהקוד בריפו הזה בתהליך ה-CI.

## עדכון

מורידים את ה-APK של הגרסה החדשה ומתקינים מעל. **הנתונים נשארים.** אנדרואיד
מאפשר עדכון רק כשהחתימה זהה — ולכן חשוב שה-CI יחתום במפתח הקבוע (ראו
"חתימה" למטה). אם ההתקנה נדחית עם "החבילה מתנגשת עם חבילה קיימת", זה סימן
שהגרסה המותקנת נחתמה במפתח אחר: מסירים את הישנה ומתקינים מחדש (ואם הטלפון
מצומד לשרת — המאגר חוזר בסבב הסנכרון הראשון; בלי שרת, מייצאים קודם).

## מה שונה בטלפון

| | במחשב | בטלפון |
|---|---|---|
| חיפוש | כל השכבות כולל "לפי משמעות" | כל השכבות המילוליות (נרמול, פונטיקה, דירוג); "לפי משמעות" זמין במחשב בלבד |
| הצפנה במנוחה | SQLCipher, מפתח שחזור | הצפנת הקבצים של אנדרואיד (פעילה כשיש נעילת מסך); המאגר בתיקייה הפרטית של האפליקציה |
| גיבוי | יומי + להתקן חיצוני + CSV | יומי בתוך האפליקציה; העותק המלא — בשרת הסנכרון |
| ייבוא מחברות | סריקות מהדיסק | מהקבצים בטלפון (הגדרות ← מחברות); צילום ישיר מהמצלמה — בהמשך |
| ניווט | סרגל צד | סרגל תחתון + כפתור "+" צף |

## סנכרון עם המחשב

הגדרות ← **סנכרון בין מכשירים** ← כתובת השרת + קוד צימוד (מהשרת, או
"קוד למכשיר נוסף" במחשב המצומד). המאגר יורד לטלפון בסבב הראשון. שרת ברשת
הביתית (`http://192.168.x.x:8787`) עובד רק כשהטלפון באותה רשת; שרת
באינטרנט ([`server/HOSTING.md`](../server/HOSTING.md)) — מכל מקום.

## חתימה (למי שמתחזק את הריפו)

ה-CI חותם את ה-APK במפתח ששמור ב-GitHub → Settings → Secrets and variables →
Actions:

| Secret | תוכן |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | קובץ ה-`.jks` בקידוד base64 |
| `ANDROID_KEYSTORE_PASSWORD` | הסיסמה של הקובץ ושל המפתח |
| `ANDROID_KEY_ALIAS` | `otzar` |

בלי ה-Secrets ה-CI חותם במפתח חד־פעמי ומזהיר: ה-APK יותקן, אבל הבא אחריו לא
יתעדכן מעליו. את המפתח **לא** מכניסים לריפו (SECURITY.md).

## בנייה מקומית (למפתחים)

Android Studio (או cmdline-tools) עם `platforms;android-35`,
`build-tools;35.0.0`, `ndk;27.2.12479018`; Java 21; `rustup target add
aarch64-linux-android`; ואז:

```sh
export ANDROID_HOME=~/Android/Sdk NDK_HOME=$ANDROID_HOME/ndk/27.2.12479018
pnpm --filter @yanuka/desktop tauri android build --apk --target aarch64
```

`gen/android/app/keystore.properties` (מחוץ ל-git) מגדיר את מפתח החתימה;
בלעדיו נבנה APK לא חתום.
